# Task 11. UIController

## 목표

프로토타입 전투 중 플레이어 HP와 게임 오버 상태를 UI로 표시한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/UIController.cs`
- 부착 대상: `UI Canvas`

## 선행 Task

- Task 01. Health
- Task 02. GameManager

## 구현 범위

- 플레이어 현재 HP와 최대 HP를 표시한다.
- HP 변화 시 UI를 갱신한다.
- 선택 사항으로 생존 시간을 표시한다.
- 게임 오버 상태가 되면 게임 오버 패널 또는 텍스트를 표시한다.
- 재시작 안내 문구를 표시한다.
- UI 참조는 Inspector에서 연결 가능하게 한다.

## 완료 조건

- 플레이어 HP가 화면에 표시된다.
- 플레이어가 피해를 받으면 HP 표시가 갱신된다.
- 게임 오버가 되면 안내 UI가 표시된다.
- UI가 전투 화면을 과도하게 가리지 않는다.

## 제외 범위

- 아이템/세트 UI.
- 결과 정산 UI.
- 애니메이션이 포함된 정식 HUD.
