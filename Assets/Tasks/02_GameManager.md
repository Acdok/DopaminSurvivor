# Task 02. GameManager

## 목표

프로토타입의 플레이 상태와 게임 오버 상태를 관리한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/GameManager.cs`
- 부착 대상: 씬의 `GameManager` 오브젝트

## 선행 Task

- Task 01. Health

## 구현 범위

- 플레이 중 상태와 게임 오버 상태를 구분한다.
- 플레이어 `Health`의 사망 이벤트를 수신한다.
- 플레이어가 사망하면 게임 오버 상태로 전환한다.
- 다른 컴포넌트가 현재 게임 오버 여부를 확인할 수 있게 한다.
- 게임 오버 이벤트를 외부 컴포넌트가 구독할 수 있게 제공한다.
- 재시작 입력을 받으면 현재 씬을 다시 로드한다.
- 종료 입력은 프로토타입 환경에 맞게 Editor/Build 분기 처리를 고려한다.

## 완료 조건

- 씬 시작 시 플레이 상태로 초기화된다.
- 플레이어 HP가 0 이하가 되면 게임 오버 상태가 된다.
- 게임 오버 상태가 한 번만 발생한다.
- 재시작 입력으로 현재 씬을 다시 시작할 수 있다.

## 제외 범위

- 저장/불러오기.
- 결과 정산 화면.
- 세트 시너지 또는 성장 시스템 상태 관리.
