# Task 03. PlayerController

## 목표

키보드 입력으로 플레이어를 2D Top View 방식으로 이동시킨다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/PlayerController.cs`
- 부착 대상: `Player`

## 선행 Task

- Task 01. Health
- Task 02. GameManager

## 구현 범위

- WASD와 방향키 입력을 지원한다.
- 상하좌우 및 대각선 이동을 지원한다.
- 대각선 이동 시 방향 벡터를 정규화한다.
- `Rigidbody2D` 기반 이동을 사용한다.
- 이동 속도는 Inspector에서 조정 가능하게 한다.
- 입력이 없으면 정지한다.
- 플레이어가 사망했거나 게임 오버 상태면 입력과 이동을 중단한다.

## 완료 조건

- 플레이어가 입력 방향으로 끊김 없이 이동한다.
- 대각선 이동이 단일 축 이동보다 빨라지지 않는다.
- 입력이 없을 때 플레이어가 정지한다.
- 플레이어 사망 후 이동할 수 없다.

## 제외 범위

- 애니메이션 방향 전환.
- 대시, 회피, 이동 스킬.
- 경계 벽 또는 맵 제한 처리.
