# Task 07. Projectile

## 목표

플레이어가 발사하는 기본 발사체의 이동, 충돌, 데미지, 수명 처리를 구현한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/Projectile.cs`
- 부착 대상: `ProjectilePrefab`

## 선행 Task

- Task 01. Health
- Task 05. EnemyController

## 구현 범위

- 생성 시 전달받은 방향으로 직선 이동한다.
- 속도, 데미지, 수명을 가진다.
- 발사체 값은 초기화 메서드 또는 Inspector 기본값으로 설정 가능하게 한다.
- Enemy와 충돌하면 Enemy의 `Health`에 데미지를 적용한다.
- 명중하면 즉시 제거되어 같은 발사체가 여러 번 피해를 주지 않게 한다.
- 수명이 끝나면 자동 제거된다.
- Player에게는 피해를 주지 않는다.

## 완료 조건

- 발사체가 지정 방향으로 직선 이동한다.
- 발사체가 적에게 닿으면 적 HP가 감소한다.
- 명중한 발사체는 제거된다.
- 적에게 닿지 않아도 수명 종료 시 제거된다.

## 제외 범위

- 관통, 반사, 유도.
- 폭발 범위 피해.
- 발사체 풀링.
