# Task 08. AutoTargeting

## 목표

플레이어 기준 가장 가까운 살아있는 Enemy를 찾는 자동 조준 컴포넌트를 구현한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/AutoTargeting.cs`
- 부착 대상: `Player`

## 선행 Task

- Task 01. Health
- Task 05. EnemyController

## 구현 범위

- 현재 씬의 Enemy 후보를 탐색한다.
- 플레이어 위치에서 가장 가까운 유효 대상을 선택한다.
- 사망했거나 비활성화된 적은 타겟에서 제외한다.
- 적이 없으면 null 또는 실패 결과를 반환한다.
- 탐색 방식은 프로토타입 단순성을 우선하되, 추후 최적화 가능하게 메서드 경계를 둔다.
- 타겟 조회용 공개 메서드를 제공한다.

## 완료 조건

- 적이 하나 있으면 해당 적을 타겟으로 반환한다.
- 적이 여러 명이면 가장 가까운 적을 반환한다.
- 적이 없으면 공격용 타겟을 반환하지 않는다.
- 사망한 적은 타겟으로 선택하지 않는다.

## 제외 범위

- 시야각, 장애물 차폐 판정.
- 우선순위 타겟팅.
- 타겟 락온 UI.
