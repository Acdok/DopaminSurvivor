# Task 10. EnemySpawner

## 목표

프로토타입 전투 루프 검증을 위해 일정 시간마다 적을 생성한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/EnemySpawner.cs`
- 부착 대상: 씬의 `EnemySpawner` 오브젝트

## 선행 Task

- Task 02. GameManager
- Task 05. EnemyController

## 구현 범위

- Enemy 프리팹을 Inspector에서 지정한다.
- 생성 주기, 한 번에 생성할 수, 최대 활성 적 수를 Inspector에서 조정 가능하게 한다.
- 플레이어 주변 또는 카메라 화면 외곽 기준으로 생성 위치를 계산한다.
- 최대 활성 적 수를 넘으면 추가 생성하지 않는다.
- 생성된 적이 Player를 추적할 수 있도록 필요한 참조를 연결한다.
- 생존 시간 1분마다 보스를 생성하고, 별도 보스 프리팹이 없으면 Enemy 프리팹을 강화해 사용한다.
- 보스 처치 시 보상 상자를 드롭하도록 보스 상자 드롭 컴포넌트를 보장한다.
- 게임 오버 상태에서는 추가 생성을 중단한다.

## 완료 조건

- 씬 실행 후 일정 시간마다 적이 생성된다.
- 생성된 적이 플레이어를 향해 이동한다.
- 최대 활성 적 수 제한이 동작한다.
- 1분마다 보스가 생성되고 보스 사망 시 보상 상자가 드롭된다.
- 게임 오버 후 새 적이 생성되지 않는다.
