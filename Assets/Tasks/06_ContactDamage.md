# Task 06. ContactDamage

## 목표

적이 플레이어와 접촉 중일 때 일정 간격으로 접촉 데미지를 적용한다.

## 구현 대상

- 예정 스크립트: `Assets/Scripts/ContactDamage.cs`
- 부착 대상: `Enemy`

## 선행 Task

- Task 01. Health
- Task 05. EnemyController

## 구현 범위

- 접촉 데미지 값을 Inspector에서 조정 가능하게 한다.
- 피해 적용 간격을 Inspector에서 조정 가능하게 한다.
- Player와 접촉하면 Player의 `Health`에 데미지를 적용한다.
- 접촉 상태가 유지되어도 매 프레임 피해를 주지 않도록 타이머를 둔다.
- 접촉이 끝났다가 다시 시작되어도 피해 간격 규칙을 유지한다.
- 적 또는 플레이어가 사망한 상태면 데미지를 적용하지 않는다.

## 완료 조건

- 적이 플레이어와 닿으면 플레이어 HP가 감소한다.
- 접촉 상태에서 HP가 매 프레임 감소하지 않는다.
- 설정된 피해 간격이 지난 뒤에만 추가 피해가 들어간다.
- 플레이어 사망 후 추가 접촉 피해가 적용되지 않는다.
