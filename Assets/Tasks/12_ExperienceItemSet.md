# Task 12. Experience Item Set

## 목표

적 처치 후 경험치 획득, 레벨업 보상 3택, 아이템 보유, 세트 시너지 표시를 프로토타입으로 구현한다.

## 구현 대상

- `JIN_PlayerExperience`
- `JIN_EnemyXpDropper`
- `JIN_XpPickup`
- `JIN_PlayerItemInventory`
- `JIN_LevelUpRewardController`
- `JIN_SetSynergyController`
- `JIN_GrowthUIController`
- `JIN_SetSynergyUIController`
- `JIN_BossChestDropper`
- `JIN_BossRewardChest`

## 구현 범위

- 적 사망 시 경험치 구슬을 생성한다.
- 플레이어가 경험치 구슬을 획득하면 XP와 레벨을 갱신한다.
- 초반 요구 XP는 낮고, 이후 레벨 요구량은 점진적으로 증가한다.
- 레벨업 시 기획 아이템 중 3개 선택지를 표시하고 하나를 선택한다.
- 레벨업 선택지는 아이템 1~5티어 확률 `20/30/30/15/5`를 따른다.
- 보스 처치 시 보상 상자를 드롭하고, 아이템 1~5티어 확률 `0/10/30/40/20`를 따른다.
- 아이템 데이터는 효과 방식(스탯 증가/무기 추가/패시브/랜덤 옵션), 티어, 아이작식 짧은 설명, 프로토타입 문자 아이콘을 포함한다.
- 아이템 선택 시 보유 아이템 레벨과 세트 진행도를 갱신한다.
- XP 바, 레벨, 좌측 세트 패널, 세트별 보유 아이템 상세를 표시한다.
- 세트 상세에는 보유 아이템 아이콘형 슬롯을 표시하고, 마우스 오버 시 아이템 효과 설명 오버레이를 표시한다.
- 레벨업 보상에 The Binding of Isaac식 혈사포 아이템을 포함하고, 획득 시 기본 공격을 충전형 관통 레이저로 전환한다.
- 혈사포 아이템의 과충전 사격 세트 효과가 발동하면 유도 혈사포 옵션을 켠다.
- 레벨업 보상에 혈사포 세트 효과와 별개로 모든 기본 공격에 유도를 부여하는 범용 유도 아이템을 포함한다.
- 레벨업 보상에 더블샷, 트리플샷, 쿼드샷 아이템을 포함하고, 획득한 최고 단계에 따라 공격 수를 2/3/4로 전환한다.
- 레벨업 보상에 적중 시 현재 무기 형태를 따른 약한 분열 공격을 생성하는 아이템을 포함한다.

## 제외 범위

- 각 아이템의 고유 투사체/장판/드론 연출 완성.
- 정식 밸런스 테이블.
- 아이템 아트 리소스와 애니메이션.
