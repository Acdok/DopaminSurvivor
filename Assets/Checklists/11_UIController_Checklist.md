# Checklist 11. UIController

## 에디터 설정

- [ ] 씬에 `UI Canvas`가 있다.
- [ ] `UIController`가 `UI Canvas` 또는 UI 관리 오브젝트에 부착되어 있다.
- [ ] Player `Health` 참조가 연결되어 있다.
- [ ] `GameManager` 참조가 연결되어 있다.
- [ ] HP 표시 텍스트 또는 게이지 참조가 연결되어 있다.
- [ ] 게임 오버 UI 참조가 연결되어 있다.

## 동작 검증

- [ ] 씬 시작 시 Player 현재 HP와 최대 HP가 표시된다.
- [ ] Player가 피해를 받으면 HP 표시가 갱신된다.
- [ ] Player HP가 0 이하가 되면 게임 오버 UI가 표시된다.
- [ ] 재시작 안내 문구가 표시된다.
- [ ] UI가 전투 화면의 핵심 영역을 과도하게 가리지 않는다.
- [ ] 생존 시간 표시를 사용하는 경우 시간이 정상 증가하고 게임 오버 시 멈춘다.
- [x] XP 바와 현재 레벨 표시가 런타임 HUD로 생성된다.
- [x] 아이템 획득 후 좌측 세트 시너지 패널이 갱신된다.
- [x] 세트 시너지 패널에서 보유 아이템 상세를 확인할 수 있다.

## 통과 기준

- [ ] 플레이어 상태와 게임 오버 여부를 화면에서 즉시 확인할 수 있다.
- [ ] Console에 반복 에러가 발생하지 않는다.
