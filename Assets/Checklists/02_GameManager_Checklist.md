# Checklist 02. GameManager

## 에디터 설정

- [ ] 씬에 `GameManager` 오브젝트가 있다.
- [ ] `GameManager` 컴포넌트가 부착되어 있다.
- [ ] Player의 `Health` 참조가 연결되어 있다.
- [ ] 재시작 입력 키가 확인되어 있다.

## 동작 검증

- [ ] 씬 시작 시 게임 상태가 플레이 중으로 초기화된다.
- [ ] Player HP가 0 이하가 되면 게임 오버 상태가 된다.
- [ ] 게임 오버 이벤트가 1회만 발생한다.
- [ ] 게임 오버 후 재시작 입력으로 현재 씬이 다시 로드된다.
- [ ] 게임 오버 후 종료 입력이 프로토타입 환경에 맞게 처리된다.

## 통과 기준

- [ ] 다른 컴포넌트가 게임 오버 여부를 안정적으로 조회할 수 있다.
- [ ] Console에 반복 에러가 발생하지 않는다.
