# Checklist 12. Experience Item Set

## 구현 결과

- [x] 적 사망 시 `JIN_EnemyXpDropper`가 XP 구슬을 생성한다.
- [x] `JIN_XpPickup`이 플레이어 접촉 또는 근접 흡수로 XP를 지급한다.
- [x] `JIN_PlayerExperience`가 레벨, 현재 XP, 다음 레벨 요구 XP를 관리한다.
- [x] 초반 요구 XP가 낮고 레벨이 오를수록 요구 XP가 증가한다.
- [x] 레벨업 시 `JIN_LevelUpRewardController`가 3개 아이템 선택지를 표시한다.
- [x] 선택지는 `mds/아이템규칙.md`의 등급/확률/효과 방식 규칙을 기반으로 구성된다.
- [x] `JIN_ItemData`가 효과 방식(스탯 증가/무기 추가/패시브/랜덤 옵션), 1~5티어, 문자 아이콘, 아이작식 짧은 설명을 가진다.
- [x] 일반 레벨업 선택지는 1~5티어 확률 `20/30/30/15/5`를 사용한다.
- [x] 보스 상자 보상용 public API가 1~5티어 확률 `0/10/30/40/20`을 사용한다.
- [x] `JIN_BossChestDropper`와 `JIN_BossRewardChest`가 보스 처치 후 상자 드롭/획득을 처리한다.
- [x] `EnemySpawner`가 1분마다 생성한 보스에 보스 상자 드롭 컴포넌트를 보장한다.
- [x] 아이템 획득 시 `JIN_PlayerItemInventory`가 보유 레벨을 갱신한다.
- [x] 아이템 효과와 세트 단계 보너스가 기본 전투 수치에 반영된다.
- [x] XP 바와 레벨 표시 UI가 런타임에 생성된다.
- [x] 좌측 세트 시너지 패널이 보유 세트만 표시한다.
- [x] 세트 패널을 선택하면 해당 세트에 포함된 보유 아이템과 레벨을 확인할 수 있다.
- [x] 세트 상세에 보유 아이템 아이콘형 슬롯이 표시된다.
- [x] 보유 아이템 슬롯 마우스 오버 시 아이템 티어/효과 방식/설명 오버레이가 표시된다.
- [x] 레벨업 보상 풀에 `혈사포` 아이템이 포함된다.
- [x] `혈사포` 아이템 획득 시 기본 공격이 충전형 관통 레이저로 전환된다.
- [x] `혈사포` 보유 중 과충전 사격 세트 효과가 발동하면 유도 혈사포가 켜진다.
- [x] 레벨업 보상 풀에 혈사포 세트 효과와 별개인 `유도 칩` 아이템이 포함된다.
- [x] `유도 칩` 아이템 획득 시 일반 투사체와 혈사포 모두 범용 유도 공격 옵션을 사용한다.
- [x] 레벨업 보상 풀에 `더블샷`, `트리플샷`, `쿼드샷` 아이템이 포함된다.
- [x] 획득한 멀티샷 아이템의 최고 단계에 따라 공격 수가 2/3/4로 전환된다.
- [x] 레벨업 보상 풀에 `분열 탄환` 아이템이 포함된다.
- [x] `분열 탄환` 획득 시 적중 지점에서 현재 무기 형태를 따른 약한 분열 공격이 생성된다.
- [x] `유도 칩` 보유 중에는 분열 공격도 유도 기능을 가진다.
- [x] 새 입력 처리는 Old Input의 `Input.GetKeyDown`/`KeyCode`만 사용한다.
- [x] 레벨업 3택 UI는 EventSystem이 막혀도 Old Input 마우스 클릭 좌표로 선택 가능하다.
- [x] 좌측 세트 패널은 EventSystem이 막혀도 Old Input 마우스 클릭 좌표로 상세 선택 가능하다.

## 수동 검증

- [ ] Unity Play Mode에서 적 처치 후 XP 구슬이 떨어지는지 확인한다.
- [ ] XP 구슬 획득 후 XP 바와 레벨 텍스트가 갱신되는지 확인한다.
- [ ] 레벨업 3택 UI에서 숫자키 1/2/3 또는 버튼 선택이 동작하는지 확인한다.
- [ ] 아이템 선택 후 좌측 세트 패널과 상세 아이템 목록이 갱신되는지 확인한다.
- [ ] 보유 아이템 슬롯 위에 마우스를 올렸을 때 설명 오버레이가 표시되는지 확인한다.
- [ ] `JIN_LevelUpRewardController.TryOpenBossChestReward(3)` 호출 시 보스 상자 보상 선택지가 열리는지 확인한다.
- [ ] Boss 역할 오브젝트에 `JIN_BossChestDropper`를 붙이고 사망 시 상자가 드롭되는지 확인한다.
- [ ] 상자 접촉 시 보스 상자 확률 기반 보상 선택지가 열리는지 확인한다.
- [ ] Console에 반복 에러가 발생하지 않는지 확인한다.
