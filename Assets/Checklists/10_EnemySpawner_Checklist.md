# Checklist 10. EnemySpawner

## 에디터 설정

- [ ] 씬에 `EnemySpawner` 오브젝트가 있다.
- [ ] `EnemySpawner` 컴포넌트가 부착되어 있다.
- [ ] Enemy 프리팹이 연결되어 있다.
- [ ] Player Transform이 연결되어 있다.
- [ ] 생성 주기, 생성 수, 최대 활성 적 수가 Inspector에 노출된다.
- [x] 보스 생성 사용 여부, 1분 생성 주기, 보스 강화 배율, 보스 상자 보상 수가 Inspector에 노출된다.

## 동작 검증

- [ ] 씬 시작 후 설정된 주기마다 Enemy가 생성된다.
- [ ] 한 번에 생성되는 Enemy 수가 설정값과 일치한다.
- [ ] 생성된 Enemy가 Player를 향해 이동한다.
- [ ] 최대 활성 적 수에 도달하면 추가 생성이 멈춘다.
- [ ] Enemy가 제거되면 다시 생성 여유가 생긴다.
- [ ] 게임 오버 후 추가 Enemy가 생성되지 않는다.
- [x] 생성된 Enemy에 XP 드롭 컴포넌트가 자동으로 보장된다.
- [x] 생존 시간 1분마다 보스가 생성되도록 보스 타이머가 추가된다.
- [x] 보스 사망 시 보상 상자 드롭 컴포넌트가 자동으로 보장된다.

## 통과 기준

- [ ] 성장 시스템 없이도 1분 이상 기본 전투 루프를 테스트할 수 있다.
- [ ] Console에 반복 에러가 발생하지 않는다.
