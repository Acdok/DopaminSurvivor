# Checklist 09. WeaponController

- [ ] `Player`에 `WeaponController`가 부착되어 있다.
- [ ] `Player`에 `AutoTargeting`이 부착되어 있다.
- [x] 기본 공격이 `ProjectilePrefab`을 사용하는 일반 투사체로 동작한다.
- [ ] 발사 위치 Transform이 연결되어 있다.
- [x] SampleScene의 기본 일반 공격 주기가 약 0.35초로 설정된다.
- [x] SampleScene의 혈사포 충전 주기가 약 1.5초로 설정된다.
- [x] 공격 수, 부채꼴 확산 각도, 더블샷 평행 간격이 Inspector에 노출된다.
- [x] 공격 주기, 데미지, 기존 속도 호환 값이 Inspector에 노출된다.
- [x] 혈사포 사용 여부가 Inspector에 노출된다.
- [x] 범용 유도 공격 사용 여부와 일반 투사체 유도 회전/재탐색 값이 Inspector에 노출된다.
- [x] 분열 공격 사용 여부와 분열 수/각도/위력/속도/크기/수명이 Inspector에 노출된다.
- [x] 혈사포 충전/레이저 길이/폭/지속시간/데미지 배율이 Inspector에 노출된다.
- [x] 유도 혈사포 사용 여부, 유도 반경, 목표 수, 곡선 강도가 Inspector에 노출된다.
- [x] 짧은 화면 흔들림 설정이 Inspector에 노출된다.

## 동작 검증

- [x] Enemy가 없으면 충전 완료 후에도 레이저가 생성되지 않는다.
- [x] Enemy가 있으면 공격 주기 완료 시 일반 투사체가 생성된다.
- [x] 가장 가까운 Enemy 방향으로 일반 투사체가 발사된다.
- [x] 공격 수가 2이면 평행한 2개 공격이 발사된다.
- [x] 공격 수가 3 또는 4이면 부채꼴 방향으로 공격이 발사된다.
- [x] 범용 유도 옵션이 켜지면 일반 투사체가 목표를 추적한다.
- [x] 분열 공격 옵션이 켜지면 일반 투사체 적중 시 같은 투사체 프리팹의 절반 크기 분열 공격이 생성된다.
- [x] 분열 공격 옵션이 켜지면 혈사포에 처음 맞은 적마다 절반 두께의 혈사포 분열 공격이 1회 생성된다.
- [x] 범용 유도 옵션이 켜지면 분열 공격도 목표를 추적한다.
- [x] 혈사포 옵션이 켜지면 공격 주기 완료 시 `JIN_BrimstoneLaser`가 생성된다.
- [x] 혈사포 옵션이 켜지면 가장 가까운 Enemy 방향으로 직선 혈사포가 발사된다.
- [x] 혈사포 초당 데미지는 `ProjectileDamage * laserDamageMultiplier` 기준으로 계산된다.
- [x] 직선 혈사포가 레이저 경로 위 여러 Enemy를 관통 피해 처리한다.
- [x] 혈사포 위에 머무는 Enemy는 지속시간 동안 프레임 독립적인 지속 피해를 받는다.
- [x] 유도 옵션이 켜지면 범위 내 Enemy를 차례대로 연결하는 곡선 레이저 경로를 만든다.
- [x] 레이저 지속시간 동안 새로 경로에 들어온 Enemy도 1회 피해를 받을 수 있다.
- [x] Player 사망 또는 게임 오버 후 충전/발사가 중단된다.
