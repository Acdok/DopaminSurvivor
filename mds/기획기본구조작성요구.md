# 역할
너는 10년차 게임 기획자야.
2D Top View 기반 슈팅게임을 다수 만들었어.

## 배경
'뱀파이어 서바이벌'같은 2D 게임을 만들고 싶어.
'뱀파이어 서바이벌'과 차이점은 아이템 시너지를 세트형식으로 만들고싶어.

# 요구사항

'기획기본구조.md'파일을 만들어줘

- 게임 기획서: [프로젝트명], 게임 개요, 핵심 컨셉, 핵심 매커니즘, 기술 명세
