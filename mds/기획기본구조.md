# 게임 기획서: [프로젝트명]

## 게임 개요

뱀파이어 서바이벌류 2D Top View 슈팅게임 기획을 위한 기본 구조 문서입니다. 플레이어는 제한된 공간에서 몰려오는 적을 상대하며, 자동 또는 반자동 공격 수단과 성장 선택지를 활용해 장시간 생존하는 것을 목표로 합니다. 본 프로젝트는 아이템 시너지를 세트 형식으로 구성하여, 장비와 능력 조합에 따른 빌드 전략을 핵심 재미로 설계합니다.

## 핵심 컨셉

### 한 줄 컨셉

- 몰려오는 적을 자동 전투로 처치하며, 아이템 세트 시너지로 빌드를 완성하는 2D Top View 생존 슈팅게임.

### 핵심 차별점

- 아이템을 개별 강화가 아닌 `세트` 단위로 조합한다.
- 같은 아이템도 어떤 세트에 묶이는지에 따라 전투 스타일이 달라진다.
- 플레이어는 생존 중 선택지로 세트 완성, 세트 전환, 세트 중첩을 판단한다.

### 플레이 경험 목표

- 짧은 조작: 이동 중심의 단순한 조작.
- 빠른 성장: 레벨업/드롭 획득마다 즉시 체감되는 전투력 변화.
- 빌드 발견: 세트 조합을 실험하며 강한 조합을 찾아가는 재미.
- 압박과 역전: 적 물량 증가 속에서 시너지 완성으로 전세를 뒤집는 재미.

### 게임 루프

1. 적 처치 및 경험치/재화 획득
2. 레벨업 또는 보상 선택
3. 아이템 획득/강화/세트 조건 충족
4. 세트 효과 발동으로 전투 방식 변화
5. 더 강한 웨이브에 대응하며 생존 시간 연장

### 세트 시너지 방향

- 공격 세트: 발사체, 폭발, 관통, 지속 피해 등 화력 강화.
- 방어 세트: 보호막, 회복, 피해 감소, 넉백 등 생존성 강화.
- 기동 세트: 이동 속도, 회피, 돌진, 위치 기반 효과 강화.
- 자원 세트: 경험치, 골드, 드롭률, 쿨타임 등 성장 효율 강화.
- 하이브리드 세트: 공격과 방어/기동/자원을 섞어 특정 플레이 스타일 제공.

### 개발 기준

- 모든 아이템은 단독 효과와 세트 기여도를 함께 가진다.
- 세트 효과는 UI에서 조건과 발동 상태를 명확히 보여준다.
- 세트는 초반 목표, 중반 강화, 후반 완성의 흐름을 만든다.
- 선택지는 무작위성이 있어도 현재 빌드와 연결된 판단 근거를 제공한다.
- 특정 세트들의 성능이 너무 약하지 않도록 공격세트를 제외한 나머지 세트들에 핵심공격능력을 가진 무기들을 배치한다.

## 핵심 매커니즘

### 목적

- 프로토타입 단계에서 플레이어와 적의 기본 전투 루프가 동작하는지 검증한다.
- 검증 범위는 이동, 공격, 피격, 사망 처리까지로 제한한다.
- 세트 시너지, 성장, 세부 밸런스는 본 섹션의 구현 범위에 포함하지 않는다.

### 공통 전제

- 게임 화면은 2D Top View 기준으로 구성한다.
- 플레이어와 적은 모두 충돌 판정을 가진다.
- HP가 0 이하가 된 캐릭터는 사망 상태로 전환된다.
- 데미지, 이동 속도, 공격 주기, HP 수치는 임시값으로 설정하되, 인스펙터 또는 설정값에서 조정 가능하게 둔다.

### 플레이어

#### 이동

- 입력 방식: 키보드 WASD 또는 방향키 입력을 받는다.
- 이동 방식: 입력 방향으로 즉시 이동한다.
- 이동 방향: 상하좌우 및 대각선 이동을 지원한다.
- 대각선 보정: 대각선 이동 시 속도가 과도하게 증가하지 않도록 방향 벡터를 정규화한다.
- 검증 기준: 플레이어가 입력한 방향으로 끊김 없이 이동하고, 입력이 없을 때 정지한다.

#### 공격

- 공격 방식: 플레이어는 가장 가까운 적을 자동으로 조준한다.
- 공격 실행: 정해진 공격 주기마다 기본 발사체를 생성한다.
- 발사체 이동: 발사체는 생성 시점의 목표 방향으로 직선 이동한다.
- 명중 처리: 발사체가 적과 충돌하면 적에게 데미지를 주고 제거된다.
- 예외 처리: 화면 안에 적이 없으면 공격하지 않는다.
- 검증 기준: 적이 존재할 때 플레이어가 자동으로 발사체를 발사하고, 발사체가 적에게 닿으면 적 HP가 감소한다.

#### 피격

- 피격 조건: 플레이어가 적과 부딪히면 HP가 줄어든다.
- 데미지 처리: 충돌한 적의 기본 접촉 데미지만큼 플레이어 HP를 감소시킨다.
- 중복 피격 방지: 같은 적과 계속 겹쳐 있을 때 매 프레임 HP가 감소하지 않도록 기본 피격 간격을 둔다.
- 사망 처리: 플레이어 HP가 0 이하가 되면 이동과 공격을 중지하고 게임 오버 상태로 전환한다.
- 검증 기준: 적과 접촉하면 플레이어 HP가 감소하고, HP가 0 이하가 되면 조작 및 공격이 중단된다.

### 적

#### 이동

- 이동 방식: 적은 플레이어의 현재 위치를 향해 직선으로 이동한다.
- 추적 기준: 매 프레임 플레이어 위치를 확인하고 이동 방향을 갱신한다.
- 충돌 처리: 적은 플레이어와 충돌할 수 있으며, 접촉 상태에서도 플레이어를 향한 이동을 유지한다.
- 사망 예외: 적 HP가 0 이하가 되면 이동을 중지한다.
- 검증 기준: 적이 생성되면 플레이어를 향해 접근하고, 플레이어가 이동하면 추적 방향이 갱신된다.

#### 공격

- 공격 방식: 적의 기본 공격은 플레이어와의 접촉 데미지로 처리한다.
- 공격 조건: 적이 플레이어와 충돌 중일 때 공격 판정이 발생한다.
- 공격 주기: 플레이어의 중복 피격 방지 간격에 맞춰 접촉 데미지가 적용된다.
- 별도 발사체: 기본 프로토타입에서는 적 원거리 공격을 구현하지 않는다.
- 검증 기준: 적이 플레이어에게 닿으면 플레이어 HP가 감소한다.

#### 피격

- 피격 조건: 적이 플레이어의 발사체와 부딪히면 HP가 줄어든다.
- 데미지 처리: 발사체의 기본 데미지만큼 적 HP를 감소시킨다.
- 접촉 판정: 적이 플레이어와 부딪히면 플레이어에게 기본 접촉 데미지를 준다.
- 사망 처리: 적 HP가 0 이하가 되면 적 오브젝트를 제거한다.
- 보상 처리: 기본 프로토타입에서는 적 제거 확인까지만 검증하며, 보상 지급은 필수 범위에 포함하지 않는다.
- 검증 기준: 플레이어의 발사체가 적에게 명중하면 적 HP가 감소하고, 적이 플레이어와 접촉하면 플레이어 HP가 감소한다.

### 프로토타입 체크리스트

- [ ] 플레이어가 WASD 또는 방향키 입력으로 이동한다.
- [ ] 플레이어가 대각선 이동 시 비정상적으로 빨라지지 않는다.
- [ ] 적이 플레이어 위치를 향해 자동으로 이동한다.
- [ ] 플레이어가 가장 가까운 적을 자동으로 조준한다.
- [ ] 플레이어가 정해진 주기마다 기본 발사체를 발사한다.
- [ ] 발사체가 적에게 닿으면 적 HP가 감소한다.
- [ ] 적 HP가 0 이하가 되면 적이 제거된다.
- [ ] 적이 플레이어와 부딪히면 플레이어 HP가 감소한다.
- [ ] 접촉 상태에서 플레이어 HP가 매 프레임 감소하지 않는다.
- [ ] 플레이어 HP가 0 이하가 되면 이동과 공격이 중지된다.
- [ ] 기본 전투 루프가 성장 시스템 없이도 단독으로 검증된다.

## 아이템 구조

### 아이템 구조 목적

- 아이템은 획득 즉시 전투에 영향을 주는 단독 효과를 가진다.
- 같은 아이템을 중복 획득하면 해당 아이템의 공격 성능, 유틸리티, 발동 빈도 중 하나 이상이 강화된다.
- 아이템은 하나 이상의 세트에 연결되며, 세트 조건을 만족하면 전투 방식이 눈에 띄게 변한다.
- 공격 세트가 아닌 방어/기동/자원 세트에도 핵심 공격능력을 가진 무기를 배치해 빌드 선택지가 약해지지 않도록 한다.
- 본 섹션의 수치와 명칭은 프로토타입 이후 밸런싱을 위한 기획 기준이며, 최종 수치는 구현 테스트 결과에 따라 조정한다.

### 아이템 공통 규칙

- 아이템 획득 방식: 레벨업 보상, 필드 드롭, 보스 보상으로 획득한다.
- 아이템 등급: 기본 프로토타입 이후 `일반`, `희귀`, `세트 핵심` 등급으로 확장할 수 있다.
- 강화 단계: 아이템별 1~5레벨을 기본 기준으로 하며, 동일 아이템을 다시 획득하면 레벨이 상승한다.
- 세트 기여도: 아이템 1개당 관련 세트 조건 1개를 충족한다. 핵심 아이템은 특정 세트 조건 2개를 충족하도록 확장할 수 있다.
- 세트 발동 표시: UI에는 현재 보유 아이템, 세트 진행도, 발동 중인 세트 효과를 표시한다.
- 중복 세트: 한 아이템이 여러 세트에 속할 수 있으나, 초반 프로토타입에서는 아이템당 대표 세트 1개를 우선 적용한다.

| 행운 배터리 | 자원/확률 강화 | 드롭률과 보상 선택지의 희귀도 등장 확률을 높인다. | 드롭률 증가, 희귀 보상 확률 증가, 쿨타임 감소 | 탐욕 증폭 세트 | 아이템 획득 직후 일정 시간 모든 공격의 발사 빈도가 증가한다. |
| 화염 병 | 범위 공격 무기 | 가장 가까운 적 위치에 화염 장판을 생성한다. | 장판 크기 증가, 지속 시간 증가, 화상 피해 증가 | 연소 확산 세트 | 화상 상태의 적이 사망하면 작은 화염 장판을 추가 생성한다. |
| 폭발 캡슐 | 범위/처치 연계 | 일정 수의 적 처치 후 주변에 폭발을 일으킨다. | 필요 처치 수 감소, 폭발 범위 증가, 폭발 피해 증가 | 연소 확산 세트 | 폭발이 화염 장판을 강화하고, 강화된 장판은 적 이동 속도를 낮춘다. |
| 독성 필터 | 지속 피해/약화 | 적에게 독 중첩을 부여하는 느린 투사체를 발사한다. | 독 중첩 한도 증가, 지속 시간 증가, 방어력 감소 효과 추가 | 연소 확산 세트 | 독에 걸린 적이 화상 피해를 받을 때 추가 지속 피해가 발생한다. |
| 냉각 링 | 제어/방어 | 플레이어 주변에 냉기 파동을 주기적으로 방출해 적 이동 속도를 낮춘다. | 파동 범위 증가, 둔화율 증가, 피해 추가 | 안정 제어 세트 | 둔화된 적에게 가하는 모든 투사체 피해가 증가한다. |
| 중력 못 | 제어 공격 무기 | 지정 범위에 적을 끌어당기는 중력장을 생성한다. | 흡입력 증가, 지속 시간 증가, 중심부 피해 증가 | 안정 제어 세트 | 중력장 중심의 적에게 주기적으로 관통 탄환이 떨어진다. |
| 방전 코일 | 제어/반격 | 가까운 적이 일정 수 이상 모이면 원형 전기 충격을 방출한다. | 발동 조건 완화, 피해 증가, 마비 확률 추가 | 안정 제어 세트 | 마비된 적 처치 시 냉각 링의 다음 파동이 즉시 발동한다. |

### 세트 목록

| 세트명 | 발동 조건 | 전투 스타일 | 세트 효과 | 포함 아이템 예시 |
|---|---|---|---|---|
| 과충전 사격 세트 | 관련 아이템 3개 이상 보유 | 빠른 자동 사격과 연쇄 피해로 화면을 정리하는 공격형 빌드 | 모든 탄환 계열 공격의 발사 속도와 연쇄 성능이 증가한다. 세트 완성 시 처치한 적에게서 보조 탄환이 생성된다. | 도파민 탄환, 연쇄 스파크, 집중 렌즈 |
| 생존 반격 세트 | 관련 아이템 3개 이상 보유 | 방어막과 회복으로 버티면서 근접한 적을 반격하는 방어형 빌드 | 보호막, 회복, 반격 피해가 강화된다. 세트 완성 시 피해를 받은 직후 짧은 시간 동안 주변 공격 빈도가 증가한다. | 충격 방패, 회복 주사기, 가시 코어 |

| 탐욕 증폭 세트 | 관련 아이템 3개 이상 보유 | 경험치와 재화를 빠르게 모으며 성장 속도로 화력을 키우는 자원형 빌드 | 획득 범위, 드롭 효율, 보상 품질이 증가한다. 세트 완성 시 자원 획득이 직접 공격 탄환과 일시 화력 증가로 연결된다. | 경험치 자석, 코인 드론, 행운 배터리 |
| 연소 확산 세트 | 관련 아이템 3개 이상 보유 | 장판, 폭발, 지속 피해를 겹쳐 적 무리를 녹이는 범위형 빌드 | 화상, 독, 폭발 피해가 서로 증폭된다. 세트 완성 시 상태 이상에 걸린 적이 사망할 때 주변으로 피해 상태를 전파한다. | 화염 병, 폭발 캡슐, 독성 필터 |
| 안정 제어 세트 | 관련 아이템 3개 이상 보유 | 둔화, 흡입, 마비로 적의 접근을 통제하는 제어형 빌드 | 군중 제어 효과와 제어 대상 추가 피해가 증가한다. 세트 완성 시 제어된 적에게 자동 보조 공격이 발생한다. | 냉각 링, 중력 못, 방전 코일 |

### 세트 발동 단계

- 2개 보유: 세트 예열 효과가 발동한다. 관련 아이템의 기본 성능이 소폭 증가한다.
- 3개 보유: 세트 핵심 효과가 발동한다. 전투 방식이 바뀌는 고유 효과를 제공한다.
- 4개 이상 보유: 세트 과충전 효과가 발동한다. 관련 아이템의 발동 빈도, 범위, 피해 중 하나가 추가 강화된다.
- 동일 계열 중복 강화: 이미 발동 중인 세트의 아이템을 다시 획득하면 세트 효과 수치가 상승하되, 새 효과가 무한히 늘어나지는 않는다.

### 구현 우선순위

1. 아이템 데이터 구조: 아이템명, 타입, 기본 수치, 강화 수치, 관련 세트 ID를 ScriptableObject 또는 데이터 테이블로 분리한다.
2. 아이템 획득 처리: 아이템 획득 시 단독 효과를 즉시 적용하고, 동일 아이템이면 레벨을 증가시킨다.
3. 세트 조건 판정: 보유 아이템 목록을 기준으로 세트별 진행도를 계산한다.
4. 세트 효과 적용: 2개, 3개, 4개 이상 보유 단계에 따라 공통 전투 스탯 또는 고유 이벤트를 적용한다.
5. UI 표시: 아이템 레벨, 세트 진행도, 발동 중인 세트 효과를 전투 중 확인할 수 있게 표시한다.

## 기술 명세

### 기술 명세 목적

- 본 섹션은 `핵심 매커니즘`에 정의된 이동, 자동 공격, 피격, 사망 처리 중심의 전투 루프를 Unity 2D 프로토타입으로 구현하기 위한 기준을 정의한다.
- 구현 범위는 단일 플레이어, 단일 씬, 로컬 실행 기준으로 제한한다.
- 세트 시너지, 레벨업, 보상 선택, 장기 성장 시스템은 이후 확장을 고려하되, 현재 프로토타입의 필수 구현 범위에는 포함하지 않는다.
- 모든 수치는 밸런스 확정값이 아니라 검증용 임시값으로 취급하며, Unity Inspector에서 쉽게 조정 가능해야 한다.

### 개발 환경 및 기본 전제

- 엔진: Unity 2D 프로젝트 기준.
- 시점: 2D Top View.
- 물리: Unity 2D Physics 사용.
- 입력: Unity 기본 입력 또는 Input System 중 프로젝트 설정에 맞는 방식을 사용하되, 프로토타입에서는 WASD와 방향키를 우선 지원한다.
- 카메라: 플레이어를 중심으로 따라가는 Orthographic Camera를 사용한다.
- 실행 대상: PC 로컬 실행 기준.
- 네트워크, 서버 저장, 계정, 멀티플레이, 라이브 운영 기능은 구현하지 않는다.

### 구현 대상 오브젝트

#### Player

- 역할: 사용자가 조작하는 생존 대상.
- 필수 기능:
  - 키보드 입력 기반 2D 이동.
  - 가장 가까운 적 자동 탐색.
  - 공격 주기마다 기본 발사체 생성.
  - 적과 접촉 시 HP 감소.
  - HP가 0 이하가 되면 사망 상태 전환.
- 권장 구성:
  - `Rigidbody2D`
  - `Collider2D`
  - `SpriteRenderer`
  - `PlayerController`
  - `Health`
  - `AutoTargeting`
  - `WeaponController`

#### Enemy

- 역할: 플레이어를 추적하고 접촉 피해를 주는 기본 적.
- 필수 기능:
  - 생성 후 플레이어 위치 추적.
  - 플레이어와 접촉 시 접촉 데미지 제공.
  - 발사체 피격 시 HP 감소.
  - HP가 0 이하가 되면 제거.
- 권장 구성:
  - `Rigidbody2D`
  - `Collider2D`
  - `SpriteRenderer`
  - `EnemyController`
  - `Health`
  - `ContactDamage`

#### Projectile

- 역할: 플레이어가 발사하는 기본 공격체.
- 필수 기능:
  - 생성 시점의 방향으로 직선 이동.
  - 적과 충돌 시 데미지 적용.
  - 명중 또는 수명 종료 시 제거.
- 권장 구성:
  - `Rigidbody2D`
  - `Collider2D`
  - `SpriteRenderer`
  - `Projectile`

#### GameManager

- 역할: 프로토타입의 전체 상태를 관리한다.
- 필수 기능:
  - 플레이 상태, 게임 오버 상태 구분.
  - 플레이어 사망 이벤트 수신.
  - 게임 오버 UI 표시.
  - 재시작 또는 종료 입력 처리.

#### EnemySpawner

- 역할: 적 생성 흐름을 관리한다.
- 필수 기능:
  - 일정 시간마다 적 생성.
  - 플레이어 주변 또는 화면 외곽 기준의 생성 위치 결정.
  - 최대 적 수 제한 옵션 제공.
- 프로토타입 기준:
  - 복잡한 웨이브 테이블은 필수 구현 범위가 아니다.
  - 생성 주기, 생성 수, 최대 적 수는 Inspector에서 조정 가능하게 둔다.

### 컴포넌트 구조

#### PlayerController

- 입력 값을 읽어 이동 방향을 계산한다.
- 대각선 이동 시 방향 벡터를 정규화한다.
- `Rigidbody2D` 기반 이동을 사용해 물리 업데이트와 충돌 처리를 안정적으로 유지한다.
- 플레이어 사망 상태에서는 입력과 이동 처리를 중단한다.

#### Health

- 현재 HP와 최대 HP를 관리한다.
- 데미지 적용 함수를 제공한다.
- HP가 0 이하가 되면 사망 이벤트를 발생시킨다.
- Player와 Enemy가 공통으로 사용할 수 있게 구성한다.

#### AutoTargeting

- 현재 씬에 존재하는 적 중 가장 가까운 대상을 찾는다.
- 적이 없으면 유효한 타겟을 반환하지 않는다.
- 탐색 주기는 매 프레임 또는 짧은 간격 중 하나를 선택할 수 있으나, 프로토타입에서는 구현 단순성을 우선한다.

#### WeaponController

- 공격 쿨타임을 관리한다.
- 유효한 타겟이 있을 때 발사체를 생성한다.
- 발사체 생성 위치, 공격 주기, 데미지, 속도를 설정값으로 가진다.
- 플레이어 사망 상태에서는 공격을 중단한다.

#### Projectile

- 생성 시 전달받은 방향, 속도, 데미지 값을 가진다.
- 이동 중 적과 충돌하면 데미지를 적용한다.
- 같은 발사체가 여러 적에게 중복 피해를 주지 않도록 명중 시 제거한다.
- 일정 시간이 지나도 명중하지 않으면 자동 제거한다.

#### EnemyController

- 플레이어의 현재 위치를 기준으로 이동 방향을 갱신한다.
- `Rigidbody2D`를 통해 플레이어 방향으로 이동한다.
- 적 사망 상태에서는 이동을 중단한다.

#### ContactDamage

- 적이 플레이어와 접촉 중일 때 데미지를 적용한다.
- 플레이어가 매 프레임 피해를 받지 않도록 피격 간격을 적용한다.
- 접촉 데미지와 피격 간격은 Inspector에서 조정 가능하게 둔다.

#### CameraFollow

- 플레이어 위치를 따라 카메라를 이동한다.
- Z축과 Orthographic 설정은 고정한다.
- 카메라 이동은 즉시 추적 또는 부드러운 추적 중 하나로 구현하되, 전투 판독성을 우선한다.

#### UIController

- 플레이어 HP 표시를 갱신한다.
- 생존 시간 또는 처치 수를 표시할 수 있다.
- 게임 오버 상태에서 안내 UI를 표시한다.

### 데이터 및 설정값

#### Player 설정

- 최대 HP
- 이동 속도
- 피격 무적 시간 또는 접촉 피해 적용 간격
- 공격 주기
- 기본 발사체 데미지

- 최대 HP

- 최대 활성 적 수

#### 설정 관리 방식

- 초기 프로토타입에서는 MonoBehaviour의 serialized field로 값을 노출한다.
- 반복 조정이 필요한 값은 Inspector에서 수정 가능하게 한다.
- 추후 아이템, 세트, 성장 시스템으로 확장될 값은 ScriptableObject로 분리할 수 있으나, 현재 필수 구현은 아니다.

### 입력 명세

- 이동 입력:
  - `W` 또는 `Up Arrow`: 위 이동.
  - `S` 또는 `Down Arrow`: 아래 이동.
  - `A` 또는 `Left Arrow`: 왼쪽 이동.
  - `D` 또는 `Right Arrow`: 오른쪽 이동.
- 입력이 없으면 플레이어는 정지한다.
- 서로 반대되는 방향 입력이 동시에 들어오면 해당 축의 이동값은 0으로 처리한다.
- 대각선 입력은 정규화하여 단일 축 이동보다 빠르지 않게 한다.
- 공격은 자동으로 실행되며, 별도 공격 버튼은 프로토타입 필수 범위에 포함하지 않는다.
- 게임 오버 상태에서는 이동과 공격 입력을 무시한다.

### 충돌 및 물리 명세

#### Layer 권장안

- `Player`
- `Enemy`
- `Projectile`
- `Wall` 또는 `Obstacle`
- `Pickup`은 추후 확장용으로 예약 가능하다.

#### 충돌 규칙

- Player와 Enemy는 충돌 또는 Trigger 판정으로 접촉을 감지한다.
- Projectile은 Enemy와 충돌하면 데미지를 적용하고 제거된다.
- Projectile은 Player에게 피해를 주지 않는다.
- Enemy끼리의 충돌은 프로토타입에서는 필수 구현 범위가 아니다.
- Wall 또는 Obstacle이 존재할 경우 Player와 Enemy의 이동을 막을 수 있다.

#### Rigidbody2D 기준

- Player와 Enemy는 2D 물리 충돌을 위해 `Rigidbody2D`를 가진다.
- Top View 이동이므로 Gravity Scale은 0으로 설정한다.
- 회전이 필요 없다면 Z Rotation을 고정한다.
- 빠른 발사체가 충돌을 놓치지 않도록 충돌 방식 또는 이동 방식을 점검한다.

### 전투 명세

#### 자동 조준

- 플레이어 기준 가장 가까운 Enemy를 타겟으로 선택한다.
- 타겟이 사망하거나 제거되면 다음 공격 시점에 새 타겟을 찾는다.
- 타겟이 없으면 발사체를 생성하지 않는다.

#### 발사체 공격

- 공격 주기가 끝났고 유효한 타겟이 있으면 발사체를 생성한다.
- 발사 방향은 발사 순간의 `타겟 위치 - 플레이어 위치`로 계산한다.
- 발사체는 생성 이후 목표를 추적하지 않고 직선 이동한다.
- 발사체가 Enemy에게 명중하면 Enemy의 HP를 감소시킨다.

#### 접촉 피해

- Enemy가 Player와 접촉하면 Player에게 데미지를 준다.
- 접촉 상태가 유지되어도 설정된 피해 간격이 지나기 전에는 추가 피해를 주지 않는다.
- Player HP가 0 이하가 되면 GameManager에 사망 상태를 알린다.

#### 사망 처리

- Enemy 사망:
  - 이동을 중지한다.
  - 충돌 판정을 비활성화하거나 즉시 제거한다.
  - 처치 수를 사용하는 경우 UI에 반영한다.
- Player 사망:
  - 이동과 공격을 중지한다.
  - EnemySpawner의 추가 생성을 중지할 수 있다.
  - 게임 오버 UI를 표시한다.

### UI 명세

#### 플레이 중 UI

- 플레이어 현재 HP와 최대 HP를 표시한다.
- 선택 사항으로 생존 시간과 처치 수를 표시한다.
- UI는 전투 화면을 과도하게 가리지 않도록 화면 가장자리 중심으로 배치한다.

#### 게임 오버 UI

- 플레이어 HP가 0 이하가 되었을 때 표시한다.
- 최소 표시 정보:
  - 게임 오버 문구.
  - 생존 시간 또는 처치 수.
  - 재시작 안내.
- 재시작 기능은 현재 씬을 다시 로드하는 방식으로 구현할 수 있다.

#### 세트 시너지 UI 확장 고려

- 핵심 컨셉에서 요구하는 세트 조건과 발동 상태 표시는 추후 구현한다.
- 현재 프로토타입에서는 전투 루프 검증을 우선하며, 세트 UI는 필수 범위에 포함하지 않는다.

### 씬 구성

#### PrototypeScene

- 필수 오브젝트:
  - Player
  - Main Camera
  - GameManager
  - EnemySpawner
  - UI Canvas
  - EventSystem
- 선택 오브젝트:
  - 간단한 바닥 타일 또는 배경 스프라이트.
  - 이동을 제한하는 외곽 벽.
  - 테스트용 적 배치 지점.

#### Prefab 구성

- `PlayerPrefab`
- `EnemyPrefab`
- `ProjectilePrefab`
- 필요 시 `DamageText`, `HealthBar` 등의 UI Prefab은 추후 추가한다.

#### 씬 동작 흐름

1. 씬 시작 시 GameManager가 플레이 상태를 초기화한다.
2. EnemySpawner가 설정된 규칙에 따라 적을 생성한다.
3. Player는 입력에 따라 이동하고, 가장 가까운 Enemy를 자동 공격한다.
4. Projectile은 Enemy와 충돌하면 데미지를 적용한다.
5. Enemy는 Player를 추적하고 접촉 시 데미지를 준다.
6. Player HP가 0 이하가 되면 게임 오버 상태로 전환한다.

### 프로토타입 제외 범위

- 아이템 세트 시너지의 실제 발동 로직.
- 레벨업, 경험치, 보상 선택지.
- 골드, 상점, 영구 성장.
- 저장/불러오기.
- 서버 통신.
- 계정, 랭킹, 업적.
- 멀티플레이.
- 복잡한 적 패턴 또는 보스전.
- 정식 밸런스 테이블.
- 아트 리소스 완성도 검수.

### 프로토타입 검증 기준

- 플레이어가 WASD와 방향키로 자연스럽게 이동한다.
- 대각선 이동 속도가 단일 축 이동보다 빨라지지 않는다.
- 카메라가 플레이어를 따라가며 전투 상황을 확인할 수 있다.
- 적이 일정 시간마다 생성되고 플레이어를 향해 이동한다.
- 플레이어가 가장 가까운 적을 자동으로 조준한다.
- 공격 주기마다 발사체가 생성된다.
- 발사체가 생성 시점의 방향으로 직선 이동한다.
- 발사체가 적에게 닿으면 적 HP가 감소한다.
- 적 HP가 0 이하가 되면 적이 제거된다.
- 적이 플레이어와 접촉하면 플레이어 HP가 감소한다.
- 접촉 상태에서 플레이어 HP가 매 프레임 감소하지 않는다.
- 플레이어 HP가 0 이하가 되면 이동과 공격이 중단된다.
- 게임 오버 UI가 표시된다.
- 성장 시스템이 없어도 1분 이상 기본 전투 루프를 테스트할 수 있다.
- 주요 수치가 Inspector에서 조정 가능하다.
